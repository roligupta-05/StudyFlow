# StudyFlow

**Academic Task and Deadline Management System**

## Overview

StudyFlow is a proposed web-based application designed to help college students organize academic tasks, manage deadlines, assign priorities, and track their progress.

## Problem Statement

Students often manage assignments, practical submissions, examinations, and project deadlines across different platforms. StudyFlow aims to bring these responsibilities into one organized application.

## Planned Features

* User registration and login
* Create, view, update, and delete academic tasks
* Deadline and priority management
* Task status tracking
* Dashboard with task summaries
* Filtering by subject, status, and priority
* Persistent storage using MySQL

## Planned Technology Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Java and Spring Boot
* **Database:** MySQL
* **Version Control:** Git and GitHub

## Development Approach

The project will follow Software Engineering practices, including requirements analysis, system modelling, implementation, testing, and maintenance.

## Current Status

Project proposal and initial SRS documentation are in progress. Application development has not yet been completed.

## Project Scope

Version 1 is intended for individual students using personal accounts. AI recommendations, shared tasks, WhatsApp notifications, and a native mobile application are outside the initial scope.
